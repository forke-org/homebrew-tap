# Forke Homebrew tap

Install the [Forke Mail](https://www.forke.space/docs/forke-mail) CLI with [Homebrew](https://brew.sh) on macOS or Linux:

```sh
brew install forke-org/tap/forke-mail
```

Then sign in and set up a project:

```sh
forke-mail login
forke-mail init
```

Update with `brew upgrade forke-mail`.

The formula installs the official release binaries from [forke-org/forke-mail](https://github.com/forke-org/forke-mail/releases) and checks their SHA-256. It updates itself within an hour of every new CLI release.
